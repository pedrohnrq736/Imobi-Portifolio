# Projeto: Portal Imobiliário High-End (Portfólio)
- Stack: HTML5 semântico, Tailwind CSS (via CDN para agilidade ou CLI) e JavaScript ES6+ modular.
- Design System: Visual clean e sofisticado (estilo Apple/Airbnb). Paleta: Fundo branco/cinza muito claro (#F8FAFC), texto grafite (#0F172A), cor primária Azul Marinho (#1E3A8A) e destaque em Dourado/Âmbar (#D97706).
- Tipografia: Google Fonts 'Plus Jakarta Sans' para títulos e 'Inter' para textos.
- Regras de Código:
  - Dados mockados (mínimo 12 imóveis variados) devem ficar isolados em `js/data.js`.
  - Use imagens reais de arquitetura/interiores via URLs do Unsplash.
  - Todo componente deve ser 100% responsivo (Mobile-First).
  - Economia de tokens: Ao editar, entregue apenas os trechos alterados.
